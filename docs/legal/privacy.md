# حریم خصوصی (پیش‌نویس MVP)

## داده‌های جمع‌آوری‌شده

- مشخصات حساب (نام کاربری، ایمیل، موبایل)
- سفارش‌ها، پرداخت‌ها و تراکنش‌های کیف پول
- متادیتای کمپین و تبلیغ

## استفاده از داده

ارائه سرویس، پشتیبانی، ممیزی امنیتی و گزارش‌گیری عملیاتی.

## نگهداری

داده‌ها تا مدت لازم برای تعهدات قانونی و مالی نگهداری می‌شوند.

## امنیت

توکن API و اطلاعات درگاه در لاگ‌های عمومی نمایش داده نمی‌شوند.
